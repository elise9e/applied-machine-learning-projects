# Machine Learning Project Portfolio
### Developed by Elise Eldridge
*Collaborator: Brynn Beaman*

This repository showcases a suite of machine learning applications developed during the DASC 41103 course at the University of Arkansas. 

Each directory contains the source code, datasets, and a detailed breakdown of the models implemented.

## Project Directory

### 1. [Project 1 - MS Classifiers](./Project1/README.md)
* **Focus:** Implementation and evaluation of multiple baseline classification models.


### 2. [Project 2 - Applying MLP](./Project2/README.md)
* **Focus:** Building and tuning a Multi-Layer Perceptron (MLP) neural network.


### 3. [Project 3 - Applying CNN](./Project3/README.md)
* **Focus:** Computer vision application utilizing Convolutional Neural Networks (CNN).
